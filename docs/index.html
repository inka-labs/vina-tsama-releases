Already using Vina Tsama? Update from inside the app

You don't need to download anything from this page. Vina Tsama looks for a newer version once a day.

  1. Open Vina Tsama.

    When a newer version is out, a bar at the top says “Vina Tsama … is ready to install”.

  2. Click Update, then Update now.

    Finish what you are typing first. The app restarts by itself and the page comes back after a few minutes.

  3. That's it.

    Your orders, customers and expenses are kept, and a backup is made before anything changes.

No bar at the top? Go to Settings → App & updates. It shows the version you have. Click Check now, then Update to … if one is offered.

If the update inside the app doesn't work, or your version is older than 2.1.1, download the installer above and run it as described below. It updates the copy you have and keeps your data.

Install it on a computer

For a new computer, or to update by hand. No administrator password is needed.

  1. Download the Windows file with the button at the top.

    It lands in your Downloads folder, named Vina-Tsama-…-windows.zip.

  2. Right-click the downloaded file and choose Extract All, then Extract.

    This step matters: the installer does not work from inside the zip file.

  3. In the folder that opens, double-click Install Vina Tsama.

    If Windows shows “Windows protected your PC”, click More info, then Run anyway. If it asks “Do you want to run this file?”, click Run.

  4. Wait while the window shows the progress.

    The first install downloads a few hundred MB and takes a few minutes. Keep the internet on.

  5. Vina Tsama opens in your browser.

    Next time, open Vina Tsama from the Start menu or the Desktop.

  1. Download the Mac file with the button at the top.

    It lands in your Downloads folder, named Vina-Tsama-…-mac.zip.

  2. Double-click the downloaded file to unzip it, then open the new Vina Tsama folder.
  3. Double-click Install Vina Tsama.

    The first time, macOS says it “could not verify” the installer. Click Done (not “Move to Bin”).

  4. Open System Settings → Privacy & Security, scroll down to Security and click Open Anyway.

    Confirm with your password or Touch ID. You only do this once. It appears because the installer isn't registered with Apple.

  5. Wait while the window shows the progress.

    The first install downloads a few hundred MB and takes a few minutes. Keep the internet on.

  6. Vina Tsama opens in your browser.

    Next time, open Vina Tsama from Applications, or press ⌘ Space and type “Vina”.

  1. Download the Linux file with the button at the top.

    It is named Vina-Tsama-…-linux.zip.

  2. Right-click the downloaded file and choose Extract.
  3. In the new folder, right-click Install Vina Tsama.sh and choose Run as a Program.
  4. Wait while the window shows the progress.

    The first install downloads a few hundred MB and takes a few minutes. Keep the internet on.

  5. Vina Tsama opens in your browser.

    Next time, open Vina Tsama from the apps menu.

Only the first install needs the internet. After that Vina Tsama opens straight away, with or without a connection.

Questions

Which version do I have?

In Vina Tsama, open Settings → App & updates. The version is at the top, with “Up to date” when there is nothing newer.

Will updating delete my orders or customers?

No. Updating replaces only the app. Your orders, customers and expenses are kept, and a backup is made before anything changes. Uninstalling doesn't delete your data either.

Do I need the internet to use it?

Only to install and to update. Day to day, Vina Tsama runs on your computer and works without a connection.

I had the old “VinaTsama” app. What do I do?

Close it and remove it first, then install this one. Your orders, customers and expenses are picked up by the new version automatically.

Windows: Settings → Apps → Installed apps → VinaTsama → Uninstall.
Mac: quit it, then drag VinaTsama from Applications to the Bin.

Don't run the old and the new app at the same time.

How do I remove Vina Tsama?

Windows: Settings → Apps → Vina Tsama → Uninstall.
Mac: double-click Uninstall Vina Tsama in the folder you downloaded.
Linux: run bash ~/.local/share/vinatsama-app/uninstall.sh

Your data is not deleted.

The installer stops or shows an error

Check these first:

1. The zip file was extracted (Windows: right-click → Extract All) and you opened the installer from the extracted folder.
2. The internet is on. The first install downloads a few hundred MB.
3. On a Mac, you clicked Open Anyway in System Settings → Privacy & Security.

If it still fails, take a photo of the installer window showing its last lines and send it to the person who set Vina Tsama up for you.

How do I check that a download is genuine?

Each release has a file named SHA256SUMS.txt. Compare the line for your file with the result of:

Windows (PowerShell): Get-FileHash .\Vina-Tsama-*-windows.zip
Mac / Linux: shasum -a 256 Vina-Tsama-*-mac.zip

The app does this check by itself when it updates.
